# Los sueños que no llegaron a jugar

Sitio web del proyecto transmedia sobre los delitos contra niños, niñas y adolescentes en Bogotá.
Reúne el podcast, la entrevista, el interactivo, la infografía y el texto informativo.

Hecho con React + Vite.

```bash
npm install
npm run dev      # servidor local en http://localhost:5173
npm run build    # genera la versión publicable en dist/
```

- Los textos están en `src/data.js` (para cambiar un video, edita su campo `youtube`).
- Las imágenes están en `public/img/`.
